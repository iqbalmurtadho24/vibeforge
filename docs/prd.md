# PRD — Bengkel Vibeforge (Demo & Landing)

## Nama Aplikasi
Bengkel Vibeforge

## Deskripsi Singkat
Situs demo sekaligus landing page promosi untuk template Vibeforge. Menampilkan
landing page publik dan tiga portal berbasis role (Manajemen, Admin, Client)
sebagai bukti nyata kemampuan template — dibangun MENGGUNAKAN Vibeforge itu sendiri.

## Peran Pengguna
1. **Guest/Visitor** — akses landing page publik, tidak perlu login
2. **Manajemen** — akses dashboard ringkasan lintas-admin, laporan, kebijakan
3. **Admin** — akses operasional: manajemen user, audit log, pengaturan, edit konten landing
4. **Client** — akses dashboard pribadi, profil, area playground

## Fitur Utama
- Landing page: hero, masalah, cara kerja 3 langkah, fitur, struktur proyek, CTA instalasi
- Login gerbang bersama dengan redirect otomatis per role
- Portal Manajemen: dashboard ringkasan, laporan lintas-admin
- Portal Admin: CRUD user, audit log viewer, pengaturan aplikasi, edit konten landing
- Portal Client: dashboard, profil, area playground

## Model Bisnis
Non-komersial — proyek open source untuk promosi dan showcase. Tidak ada
transaksi, langganan, atau monetisasi di dalam aplikasi ini.
